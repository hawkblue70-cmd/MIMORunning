# 러닝 하루 공유 카드(아침 제안 + 러닝 요약) 설계

- 날짜: 2026-10-15
- 상태: 진행(사용자 답 확정)
- 대체: `2026-10-15-insight-export-morning-design.md`의 "탭 카드 내보내기 아래 아침 블록"은 **없앤다**(사용자: 별도 카드였음). 그 설계의 스냅샷 저장·asOf 재계산·`InsightMorning` 조립기는 그대로 재사용.

## 사용자 결정
1. 아침 제안은 **둘 다**: 그날 아침(러닝 전) + 다음 날 아침.
2. 홈 카드에서 가져올 것: **제안 줄 + 이유 + 수치(HRV 등)**. (연속 주·누적 거리·대회 예측은 넣지 않음)
3. 버튼: 러닝 상세 **오늘의 인사이트 카드** 오른쪽 위(✦ 자리 옆) 공유 버튼.
4. 기존 탭 카드 내보내기 아래 아침 블록·"수치 표시" 칩 제거.

## 카드 구성(위 → 아래, 4:5 1080×1350, ShareCanvas.fit)
```
MIMO RUNNING                       2026. 10. 13 화 오후 6:10
[그날 아침]  오늘은 이지 8.3km · 강도 여유 있음     ← 판정 색 = 홈과 같은 displayColor
            이번 주 HRV가 평소 위로 안정적입니다. …  ← why 전체
            HRV 어젯밤 46(평소보다 높음) · 7일 평균 38(좋음) · …   ← data
            이번 주 롱런 아직 · …                    ← planLine(있으면)
──────
[오늘의 러닝]  이지런 · 쌓이는 러닝                   ← 유형 · 인사이트 제목
            다음 1~2일은 …                          ← 사실·다음 줄(앱 카드와 같은 visibleFact/next)
            19°C · 수면 높음 8시간 38분              ← 날씨·수면
            8.11 km · 6'29" · 52:40 · 135bpm
            ♥ 리듬 / 🏃 폼 / 📈 퍼포먼스 블록          ← 앱과 같은 블록 뷰(공유 컴포넌트)
──────
[다음 날 아침]  (데이터 있을 때) 제안 줄 + why + data + planLine
              (없을 때) → 다음: {방향}
```
- 앱 화면과 **같은 컴포넌트** 재사용(§5.8): 탭 블록 렌더는 `InsightCard`의 블록 뷰를 공유 뷰로 꺼내 양쪽에서 쓴다. 아침 블록도 한 뷰(`MorningSuggestionView`)를 그날·다음 날 두 번 쓴다.
- 길면 4:5 안에서 전체 축소(기존 ShareCanvas 동작). 다크 배경 고정(앱 다크 카드와 같은 톤).
- 새 판정 없음: 아침 = 스냅샷 또는 `mrReadiness` 재계산 결과 그대로, 러닝 = 상세 화면 headline·digest 그대로.

## 데이터
- `InsightMorning.Entry`의 why는 지금 첫 문장만 — 이 카드는 **전체 why**를 쓴다(Entry에 전체 why 보존, 기존 firstSentence 용도 제거 가능).
- planLine도 Entry에 포함(스냅샷에 있음, 재계산은 MRReadiness.planLine).
- 기존 우선순위 그대로: 그날 아침 = 러닝 전 스냅샷 → 재계산(줄 꼬리 없음). 다음 날 = 자정 지나고 pending 아님 → 스냅샷/재계산, 아니면 방향 줄.

# 역치(LT2) 추정 — 성장 탭 추세 카드 + 오늘의 인사이트

2026-10-01 · 가민 "젖산 역치(페이스·심박)" 개념을 본인 기록으로 추정해 두 곳에 표시한다.

## 배경
- 앱에는 LT1(이지 상한, %HRmax 공식)과 AT2(HRR 85% 공식)만 있고, **본인 데이터로 낸 역치 값**은 없다.
- 가민 LT 값은 HealthKit으로 넘어오지 않는다 → 직접 추정.
- 포인트 훈련 템포 페이스가 `(10K+하프)/2 · 임의로 정함`이다 → 정의 있는 값으로 교체.

## 결정 (2026-10-01 사용자 승인: 추천대로)
1. 범위: 엔진 + 성장 탭 카드 + 오늘의 인사이트 후보 + 템포 페이스 교체. 강도 분포 AT2 교체는 2차.
2. 역치 심박: 회귀·대회급 노력 교차, ±5bpm 일치 시 평균(보통), 한쪽만이면 그 값(낮음), 어긋나면 표시 안 함.
3. 표시 대상: 중수 이상(`LevelBucket.intermediate`+). 심박은 데이터 있을 때만.
4. 추세: 최근 6개월, 월말 기준 1점.
5. 동기부여 문장: 좋아졌을 때만.

## 정의 (문헌 = 틀, 본인 데이터 = 값)
- **역치 페이스** = 60분 대회 페이스 (Daniels T 페이스 정의). 예측 하프 등가(`mrPredict` "하프" midMin)에 앱 공통 Riegel 1.06으로 60분 거리를 풀어 페이스로.
  `d = 21097.5 × (60 / halfMin)^(1/1.06)`, `pace = 3600 / (d/1000)`.
- **역치 심박**
  - (a) `MRHRPaceModel` 역함수: 역치 페이스(15°C)의 심박. 학습 심박 범위(dataHRMin~Max) 밖이면 nil — 외삽 금지.
  - (b) 대회급 노력(`mrDetectEfforts`) 중 20~70분, 최근 180일, 같은 날·같은 시간(±5%) 러닝의 `hrAvg` 중앙값.
  - ⚠ ±5bpm은 임의로 정함 — 광학 심박 러닝 중 ±5bpm(Apple 문서)에 맞춤.
- **과거 시점** = 대회 비교와 같은 as-of 파이프라인(physiology → efforts+heat → fit → profile → predict → hrPace).

## 표시
### 성장 탭 — "역치 페이스" 카드
- 조건: 중수 이상 · 추세 점 3개 이상. 위치: 주간 지표 추세 섹션 다음.
- 월별 라인(페이스 청록 `Theme.pace`, 빠를수록 위). 현재 값 `4'58/km`, 심박 있으면 ` · 역치 심박 168bpm`.
- 문장: 첫 점 대비 최신이 3초/km 이상 빨라졌을 때만 "N개월간 M초 빨라졌어요". 아니면 생략.
- 설명: "오래 버틸 수 있는 가장 빠른 페이스(약 1시간 대회 페이스) · 본인 기록으로 낸 추정" + 근거줄.

### 오늘의 인사이트 — `RunHeadline` 후보 (중수 이상, 러닝)
- **좋은 신호 맨 앞: "역치를 밀어올린 러닝"** — 러닝 직전 기준 추정 대비 직후 기준이 3초/km 이상 빨라짐. 사실: "역치 페이스 추정 5'05 → 4'58". 축 none.
- **두 번째 사실 전용(제목 아님)**: 템포런이면 "본인 역치 대비 +4초/km"(느리면 +, 빠르면 −). 좋은 신호 맨 끝.
- 공유 카드 헤드라인은 기존 규칙대로 같은 제목.

## 보이지 않는 교체
- `MRPointPaces.tempo` = `mrThresholdPace(half 등가)`. 실패 시 기존 중간값 폴백. 하프 110분 기준 약 302초/km(기존 10K 298.6 · 하프 312.8 사이).

## 범위 밖
- 강도 분포 AT2·존 캐시 교체, 레이스 예측 화면 표기, 공유 토글.
